# 📝 Minimalist Todo App

> **#672be0** 메인 컬러를 활용한 깔끔하고 미니멀한 대시보드 스타일의 일간/주간 일정 및 생산성 관리 웹 애플리케이션입니다. 외부 프레임워크나 라이브러리 없이 순수 웹 표준 기술만으로 정교한 상태 관리와 반응형 UI를 구현했습니다.

---

## 📂 프로젝트 구조

본 프로젝트는 라이브러리와 프레임워크를 일절 사용하지 않고, 오직 3개의 기본 파일로만 깔끔하게 구성되어 있습니다.

```text
├── index.html    # 앱의 구조 및 레이아웃을 담당하는 마크업 파일
├── style.css     # 미니멀 테마 디자인, 레이아웃 및 커스텀 스크롤바가 정의된 스타일시트
└── app.js        # 비즈니스 로직, 상태 관리 및 데이터 영속성을 제어하는 스크립트

```

## ✨ 주요 기능

### 1. 기본 할 일 관리 (CRUD)

* **등록(Create)**: 카테고리를 지정하고 할 일을 입력하여 간편하게 일정을 추가합니다. 빈 값 입력 시 경고 메시지를 출력하여 데이터 무결성을 유지합니다.
* **조회(Read)**: 등록된 일정을 직관적인 리스트 형태로 한눈에 확인합니다.
* **수정(Update)**: 인라인 대화창(`prompt`)을 통해 등록된 할 일 내용을 실시간으로 간정하게 수정합니다.
* **완료 및 토글**: 완료된 할 일은 취소선과 반투명 처리가 적용되며, 필요 시 언제든 미완료 상태로 되돌릴 수 있습니다.
* **삭제(Delete)**: 불필요해진 항목은 목록에서 즉시 안전하게 제거합니다.

### 2. 고도화된 주간 뷰 (Weekly Calendar) & 달성률 시각화

* **가로형 주간 달력**: 이번 주 월요일부터 일요일까지의 일자가 가로로 나열되며, 클릭 시 해당 날짜의 일정을 독립적으로 필터링합니다.
* **주차 네비게이션**: 이전 주차 및 다음 주차로 자유롭게 이동하며 장기 일정을 조율할 수 있습니다.
* **실시간 카운트 배지**: 각 날짜 하단에 해당 날짜의 할 일 총 개수가 실시간으로 집계되어 표시됩니다.
* **오늘 날짜 강조**: 실제 오늘에 해당하는 날짜 카드에는 점선 테두리(`dashed`)와 은은한 배경색이 부여되어 높은 시각적 인지성을 제공합니다.
* **주간 프로그레스 바**: 이번 주 전체 할 일 대비 완료된 일정을 백분율로 계산하여 세련된 게이지 바 형태로 성취도를 시각화합니다.

### 3. 복합 다중 필터링 시스템

* **진행 상태 필터**: 상단 탭 버튼(전체 / 진행 / 완료)을 통해 할 일의 수행 여부에 따라 목록을 분류합니다.
* **카테고리(태그) 분류**: 할 일마다 4가지 핵심 카테고리(**일상**, **학업**, **업무**, **운동**)를 지정할 수 있으며, 전용 드롭다운 메뉴를 통해 특정 태그의 일정만 모아볼 수 있습니다. 각 카테고리는 가독성을 높이기 위해 고유의 소프트 컬러 뱃지가 할당됩니다.

### 4. 2열 분할 대시보드 및 다가오는 일정 뷰

* **1:1 균형 레이아웃**: 좌측의 '선택일 기준 Todo 관리 뷰'와 우측의 '전체 일정 가시화 뷰'가 완벽한 대칭을 이루어 세련된 생산성 도구의 무드를 완성합니다.
* **다가오는 일정**: 오늘을 포함하여 미래에 등록된 모든 할 일을 가까운 날짜순(오름차순)으로 자동 정렬하여 타임라인 형태로 보여줍니다.
* **양방향 크로스 동기화**: 좌측과 우측 목록 중 어느 곳에서 완료/수정/삭제 버튼을 조작하더라도 데이터와 UI가 실시간으로 교차 동기화됩니다.

### 5. 로컬스토리지(LocalStorage) 데이터 영속성 연동

* 할 일의 추가, 수정, 삭제, 완료 상태가 변경될 때마다 브라우저 내부 저장소에 자동으로 직렬화(`JSON.stringify`)되어 안전하게 저장됩니다.
* 페이지를 새로고침하거나 브라우저를 껐다 켜더라도 기존 데이터 구조를 자동으로 역직렬화(`JSON.parse`)하여 사용자의 이전 작업 환경을 완벽하게 복원합니다.

## 🛠 기술 스택

* **HTML5**: 시맨틱 태그 기반의 구조 설계 및 접근성 고려
* **CSS3**: Flexbox, Grid 레이아웃 시스템 구현, 커스텀 스크롤바 메커니즘, 디자인 시스템 구축
* **Vanilla JavaScript (ES6+)**: 객체 지향 상태 관리, 동적 DOM 조작, 날짜 연산 연동, 로컬스토리지 API 제어
